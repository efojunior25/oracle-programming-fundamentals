# Programming Fundamentals – Oracle University

## 📘 Overview | Visão Geral

### 🇺🇸 English

This repository contains the complete and well-structured documentation of the **Programming Fundamentals** course offered by **Oracle University**. The purpose of this project is to consolidate core programming concepts through faithful lesson translations, structured summaries, review questions and answers, and presentation ideas. It serves as a study reference, learning portfolio, and foundation for further software development studies.

This repository also demonstrates good practices in documentation, organization, and version control.

---

### 🇧🇷 Português

Este repositório contém a documentação completa e organizada do curso **Programming Fundamentals**, oferecido pela **Oracle University**. O objetivo deste projeto é consolidar os conceitos fundamentais de programação por meio de traduções fiéis das aulas, resumos estruturados, perguntas e respostas para revisão e ideias de apresentação. Ele serve como material de estudo, portfólio de aprendizado e base para estudos futuros em desenvolvimento de software.

---

## 🧠 Topics Covered | Tópicos Abordados

### 🇺🇸 English

- Computer fundamentals and history
- Programming logic and program structure
- Memory structures and data types
- Data persistence (files and databases)
- Application development lifecycle
- Documentation, version control, testing, and debugging

### 🇧🇷 Português

- Fundamentos de computadores e história da computação
- Lógica de programação e estrutura de programas
- Estruturas de memória e tipos de dados
- Persistência de dados (arquivos e bancos de dados)
- Ciclo de vida do desenvolvimento de aplicações
- Documentação, controle de versão, testes e depuração
