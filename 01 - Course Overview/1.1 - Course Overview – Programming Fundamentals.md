## 1️⃣ Visão Geral do Curso (Tradução)

Olá. Meu nome é **Vasiliy Strelnikov**, Senior Principal OCI Solution Specialist na Oracle. Hoje vou apresentar, juntamente com meu colega **Joe Greenwald**, um curso sobre **fundamentos de programação**.

Saudações a todos. Meu nome é **Joe Greenwald**, Senior OCI Learning Solutions Architect e Senior Principal Instructor da Oracle University. Entre mim e o Vasiliy, provavelmente acumulamos **mais de 80 anos de experiência em programação**.

O objetivo deste curso é apresentar os **conceitos fundamentais da programação**, começando por entender **como os computadores funcionam**, o que são, como operam e como executam tarefas.

Em seguida, abordamos o **papel do programador**, o que os programadores fazem e quais são as diferenças entre as diversas **linguagens de programação**. Não focamos em nenhuma linguagem específica, mas sim em seus **propósitos e características gerais**.

O curso também explora:

* Estruturas básicas de programas
* Lógica de programação
* Organização de código
* Persistência de dados (arquivos e bancos de dados)

Além disso, apresentamos uma visão geral do **processo de desenvolvimento de aplicações**, incluindo:

* Documentação
* Controle de versão
* Testes
* Depuração (debug)

Este curso foi criado para pessoas com **pouca ou nenhuma experiência prévia em programação**, servindo como o **primeiro passo** para quem deseja iniciar uma carreira na área.

Ao final, o aluno estará preparado para avançar no aprendizado de **qualquer linguagem de programação**, como Java, Python, SQL, JavaScript, entre outras.

## 5️⃣ Perguntas e Respostas para Estudo

### 🧩 Conceitos Básicos

**Qual é o objetivo principal do curso?**
Introduzir os fundamentos da programação para iniciantes.

**O curso ensina alguma linguagem específica?**
Não. Ele foca em conceitos gerais.

**Quem é o público-alvo do curso?**
Pessoas com pouca ou nenhuma experiência em programação.

**Por que o curso não foca em uma linguagem específica?**
Para preparar o aluno a aprender qualquer linguagem futuramente.

**Qual é o papel principal do programador?**
Criar soluções por meio de lógica e código.

---

### 💻 Computação e Programação

**O que significa entender como os computadores funcionam?**
Saber como eles processam dados e executam instruções.

**O que é lógica de programação?**
A forma estruturada de pensar e resolver problemas usando código.

**O que é sintaxe em programação?**
As regras de escrita de uma linguagem de programação.

**Por que a sintaxe é importante?**
Porque o computador só entende instruções escritas corretamente.

**O que são estruturas de código?**
Padrões usados para organizar instruções em um programa.

---

### 🗂 Organização e Dados

**O que significa persistência de dados?**
Salvar informações para uso futuro.

**Exemplos de persistência de dados?**
Arquivos e bancos de dados.

**Por que organizar componentes de um programa é importante?**
Facilita manutenção, leitura e evolução do sistema.

**O que é controle de versão?**
Sistema para gerenciar mudanças no código ao longo do tempo.

**Por que documentar o código?**
Para facilitar entendimento e manutenção.

---

### 🧪 Qualidade de Software

**O que é teste de software?**
Verificar se o programa funciona corretamente.

**O que é depuração (debug)?**
Identificar e corrigir erros no código.

**Por que testar um programa é essencial?**
Para garantir qualidade e evitar falhas.

---

### 🚀 Desenvolvimento de Aplicações

**O que é desenvolvimento de aplicações?**
Processo de criar softwares para resolver problemas.

**Quais habilidades um programador precisa desenvolver?**
Lógica, organização, documentação, testes e versionamento.

**Qual é o primeiro passo para se tornar programador?**
Aprender os fundamentos.

**O curso prepara o aluno para quais linguagens?**
Qualquer linguagem futura (Java, Python, SQL, etc).

**Por que os fundamentos são importantes?**
Porque se aplicam a todas as linguagens.

**Qual é a essência do trabalho do programador?**
Resolver problemas por meio de código.

**Qual é a proposta central deste curso?**
Criar uma base sólida para a jornada em programação.
